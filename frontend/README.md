# AppProbe dashboard

React + TypeScript + Vite UI for AppProbe static analysis.

```bash
# from repository root
make run
cd frontend
npm install
npm run dev
```

Open http://127.0.0.1:5173. The Vite proxy forwards `/api` to FastAPI on
port 8000.

```bash
npm test
npm run lint
npm run build
```

See [docs/milestone-2-9.md](../docs/milestone-2-9.md).
